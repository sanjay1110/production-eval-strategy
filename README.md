# Production Evaluation Strategy Review

**Design review document: [DESIGN_REVIEW.md](./DESIGN_REVIEW.md)**

An evaluation strategy for an AI operations assistant at a financial services company. It covers evaluation objectives, the three evaluation levels (end to end, trajectory, component), dataset design, tool evaluation, the LLM-as-judge framework, regression testing, CI/CD gates, production monitoring, and a risk assessment. The architecture diagram is at the top of the document.
